# features/

This directory is reserved for feature-based module organization.

Each feature (e.g. `assignments/`, `groups/`, `rewards/`, `priority/`) will contain:
- `components/` — feature-specific UI components
- `hooks/` — feature-specific hooks  
- `services/` — feature-specific service calls
- `types.ts` — feature-specific types

Phase 4+ will populate this directory with full feature modules.
